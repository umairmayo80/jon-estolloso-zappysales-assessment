Build a web application that allows administrators to view and modify user profiles and their associated
addresses.
Backend (Java/Spring Boot):
Create a "Base Service" that acts as a simple API.
Endpoints can return hardcoded data or maintain a simple runtime list (no persistent DB required unless
you prefer it).
Provide data for: Users (Email, First Name, Last Name) and their Addresses (A user can have multiple
addresses).
Frontend (React + MUI):
Implement a User List page showing basic info.
Implement a Modification Flow: Navigate from a User → to their specific Profile/Address management.
Manage a 1-to-many relationship: One user to multiple addresses.
Technical Requirements
Backend: Java 17+ and Spring Boot.
Frontend: React (latest), Material UI (MUI).
Navigation: Clear routing/navigation between the list and detail views.
State Management: Handling the modification of user/address data in the UI.
What We Are Evaluating (Criteria)

structure?
Navigation: Is the transition between the user list and the address modification intuitive?
Frontend Proficiency: Proper use of MUI components, responsive layout, and React best practices
(Hooks, Props, etc.).
Pragmatism: Since the backend can be hardcoded, we are looking at how well you structure the API
contracts to support the UI.
